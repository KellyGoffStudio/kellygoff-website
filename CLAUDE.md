# Notes for Claude (kellygoff.net)

Owner: Kelly Goff, sculptor, Wheaton College. Site: https://kellygoff.net

## Repo
- GitHub: KellyGoffStudio/kellygoff-website, branch `main`.
- Source is in `src/`; built output is in `dist/` (both are committed).
- Build: `python3 tools/build.py` (rebuild before committing so `dist/` matches `src/`).

## LineWorks
- Single-file tool: `src/lineworks/index.html` (Three.js). Built copy: `dist/lineworks/index.html`.
- Reads CSV time series as site data (each column becomes a signal along one lap).
- Truss mode: steel members, rib rings, wood/hose fill members, optional helical twist.
